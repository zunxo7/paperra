# Paperra

**Paperra** is a tool for working with **Cambridge International** past papers — **O Level, IGCSE, and A & AS Level**. Pick a qualification and syllabus, choose sessions, years, and paper variants, then pull past-paper PDFs and pull out questions (and mark schemes when they’re available) in one place.

Built for students and teachers who want less tab-hopping and a clearer path from “which paper” to “the actual questions on the page.”
